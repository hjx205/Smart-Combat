# Smart Combat（智能战斗）

一个 RimWorld 1.6 模组，让殖民者在战斗中更“聪明”。

## 功能
- **自动切换武器**：可为每个殖民者分别指定一把近战武器和一把远程武器。征召战斗时，角色会自动根据战况切换武器——敌人贴脸时换上近战武器，拉开距离后切回远程武器。
- **智能索敌攻击**：征召待命时，殖民者会自动攻击身边的敌人、扑灭附近的火焰，并在开火模式下自动射击最佳目标。
- **武器找回**：指定的武器被丢弃或掉落时，殖民者会在空闲时自动捡回。
- **可选兼容补丁**：附带针对 RPG Style Inventory（Sandy 的 RPG 风格装备栏）的兼容补丁。

## 使用方法
- 征召殖民者后选中角色，点击「自动切换武器」按钮即可开启（右键可设置近战 / 远程武器方案）。
- 不同殖民者可单独配置各自的武器方案。

## 兼容性
- 游戏版本：RimWorld 1.6
- 可选依赖：RPG Style Inventory（Sandy_Detailed_RPG_Inventory）

## 目录结构
- `1.6/` — 编译好的主程序集
- `RPG_Style_Inventory/` — RPG 风格装备栏兼容补丁程序集
- `Source/` — 源代码
